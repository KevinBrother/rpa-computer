# 验收任务：本机文本编辑器 Unicode 输入与修改

**用途**：证明 text_input 的 Unicode 链路、换行、以及基于截图的编辑修正能力。

## 给执行 Agent 的任务

1. `computer_open` + `computer_observe` 观察桌面。
2. 通过 GUI 启动系统自带文本编辑器（macOS: TextEdit；Windows: 记事本）。只用截图 + 键鼠。
3. 在文档中输入两行文字（内容自行选择，必须包含中文和至少一个 emoji），例如第一行一句中文、第二行英文加 emoji。
4. 通过观察截图确认两行都已正确显示；若有字符缺失/错乱，用键盘（退格等）修正。
5. 在最后追加一行，内容为当前文档的行数（根据你看到的画面判断）。
6. `computer_observe` 截取最终画面，`computer_close` 结束。**不要保存文件**（如弹保存对话框，选择不保存）。

## 硬性约束（违反即本次测试无效）

- 只使用 `computer_*` 工具；禁止终端、文件读写、剪贴板工具、AppleScript、CDP、浏览器。
- 禁止读取本机源码或项目文件。
- 输入必须用 `text_input`（普通文字）与 `key_chord`（回车/退格等控制键）；不得把快捷键当文本发。
- 完成判定以最终截图为依据；无法从截图确认的内容要如实说明。

## 协调者核对方式

- 人工核对最终截图：两行原始内容完整（中文与 emoji 无乱码）、追加行存在。
- 检查工具轨迹中无旁路；保存对话框若出现，处理过程也必须在视觉通道内完成。
