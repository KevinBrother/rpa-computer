# 验收任务：计算器 10 × 20（真实 GUI 操作）

**用途**：证明 Agent 能真实打开并操作计算器完成 10×20，而不是心算。

## 给执行 Agent 的任务

1. `computer_open` 打开会话，`computer_observe` 观察当前桌面。
2. 通过 GUI 启动系统计算器（macOS: Calculator；Windows: 计算器）。只允许用截图 + 键鼠完成启动（例如点击 Dock/图标，或用系统搜索框**键入**名称后回车）。
3. 在计算器中通过点击按钮或键盘输入表达式 `10 × 20` 并求值。
4. `computer_observe` 获取显示结果的截图。
5. 根据**最后这张截图**报告计算器显示屏上出现的数字。
6. `computer_close` 结束会话。

## 硬性约束（违反即本次测试无效）

- 只使用 `computer_*` 工具。禁止：终端/shell、AppleScript、CDP、浏览器、读写文件、任何应用专用 API。
- 禁止读取本机源码或项目文件。
- 结果必须来自计算器画面的截图观察，**不得用心算或直接给出算术答案**；如果你无法从截图确认显示内容，如实说"无法确认"。
- 每个 `computer_step` 的 `based_on` 必须使用最近一次观察的 `observation_id`。

## 协调者核对方式

- 人工核对最终截图中计算器显示为 200，且工具调用轨迹中没有旁路操作。
- 轨迹无法确认或存在旁路 → 计为无效测试，不算成功。
