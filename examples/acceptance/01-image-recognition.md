# 验收任务：受控画面图像识别（图片链路证明）

**用途**：第一步验收。证明 Agent 真的收到并理解了 MCP 返回的截图，而不是从文本提示里读答案。

## 给执行 Agent 的任务

1. 调用 `computer_open` 打开会话，然后 `computer_observe` 获取当前屏幕截图。
2. 用自然语言描述截图中可见的主要内容：有哪些窗口/区域、各区域里有什么文字或图形、大致位于画面的哪个位置（上/下/左/右/中间）。
3. 再说出画面中**最显眼的有色块或大号文字**是什么颜色/内容。
4. 完成后调用 `computer_close` 关闭会话。

## 硬性约束（违反即本次测试无效）

- 只使用 `computer_*` 工具；不得打开终端、运行 shell/AppleScript/CDP、读写文件、打开浏览器。
- 不得打开、查看或引用本机任何源码目录或项目文件。
- 不得根据"常识"猜测画面内容；所有结论必须来自你实际收到的截图。
- 如果收到的图片无法辨认，如实报告"无法辨认"，不要编造。

## 协调者核对方式（非 Agent 自评）

- 测试桌面由协调者预先布置为受控画面（例如纯色背景 + 一个大号单词），且**该答案不写入本提示**。
- 协调者将 Agent 的描述与受控画面真值人工比对；一致才算图片链路通过。
- 若 Agent 答出提示中未曾出现、只有画面里才有的内容，才是有效证据。
