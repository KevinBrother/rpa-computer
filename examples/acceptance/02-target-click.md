# 验收任务：图像坐标靶点点击

**用途**：证明模型给出的图像像素坐标经 Runtime 变换后能命中真实屏幕位置。

## 前置（协调者准备）

- 受控桌面上显示一个明显的靶点（例如一个大号彩色圆形按钮），位置不写入本提示。

## 给执行 Agent 的任务

1. `computer_open` + `computer_observe` 获取截图。
2. 在截图中找到唯一的彩色圆形靶点，给出它在**这张图片里**的中心像素坐标。
3. 使用 `computer_step` 执行一次 `click`，位置用上一步的图像坐标。
4. 再次 `computer_observe`，描述点击后画面发生的变化。
5. `computer_close` 结束。

## 硬性约束（违反即本次测试无效）

- 只使用 `computer_*` 工具；不得使用终端、文件、浏览器、AppleScript、CDP 或任何应用专用接口。
- 不得读取本机源码/项目文件；坐标必须来自你收到的截图本身，**不得用终端/AppleScript/文件读取来计算或验证坐标**。
- 每次 step 的 `based_on` 必须使用最近一次观察的 `observation_id`。

## 协调者核对方式

- 靶点应用记录真实收到的点击位置（或点击后状态变化），与 Agent 声明的图像坐标按缩放关系比对。
- 命中靶点 = 通过；未命中或坐标空间混乱（如把图像像素当屏幕点）= 失败并记录偏差。
