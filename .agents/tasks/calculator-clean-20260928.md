# 系统计算器真实操作验收
只用computer工具，截图+键鼠，禁止终端、脚本、应用接口、文件、浏览器和源码。截图若为锁屏，立即关闭会话并停止。
computer_open后observe观察桌面，通过GUI启动系统计算器（可用系统搜索框键入应用名并回车，但不能输入命令）。真实操作计算器输入10×20并求值，再获取结果截图。从最后截图读出显示数字并报告，不允许心算或凭记忆回答。无法确认就报告失败。开始计算前清除旧表达式，保证这次实际输入而非沿用屏幕旧结果。
每次step使用最新观察observation_id作为based_on。结束必须computer_close。不要打开编辑器或项目内容。
