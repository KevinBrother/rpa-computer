# 真实 Computer MCP 只读预检

这是只读连通性预检，不是 GUI 任务成功验收。不要计算任何结果。

1. 调用 computer_describe，然后 computer_open。
2. 如果成功打开会话，调用一次 computer_observe，尝试获取屏幕截图。
3. 如果收到图片，仅描述屏幕中可见的主要窗口/文字；如果是登录、锁屏、密码或安全提示，立即停止，不输入任何内容。
4. 如果截图工具报错，准确报告工具返回的错误码与信息。不得假称看到了图片，不得通过其他工具诊断，不得重试超过一次。
5. 对已打开的会话调用 computer_close，然后结束。

本次禁止 computer_step、鼠标、键盘或任意输入。只能通过上述computer工具；不能读取文件、执行命令、访问浏览器或源码。没有收到图片时必须明确写“未获得截图，未验证视觉能力”。无论成功或失败都报告实际工具结果。
