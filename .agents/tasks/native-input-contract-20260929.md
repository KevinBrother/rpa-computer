Error codes include permission_denied,no_display,unsupported_session,input_failed,invalid_key,invalid_text; no fake success. No screenshots or sleeps inside scalar injection. No global physical-key release.

Common semantics: absolute desktop native input units Windows pixels, macOS CoreGraphics points, X11 root pixels; scroll positive RIGHT/DOWN in wheel ticks. Key::Character supports ASCII letters/digits (physical/layout key for chords, NOT Unicode text injection); invalid others rejected before effects. All named keys supported. text_scalar valid unicode scalar, NUL rejected, \n or \r each produce ONE Return click (CRLF normalized once by caller), \t ONE Tab click. Text never clipboard. Supplementary Unicode handled correctly, per-code-unit matching releases. Drivers must attempt cleanup of their own partial transient scalar events and report failure; no release of unrelated user input. Session wrapper core owns normal key/button held state, records BEFORE dispatch (partial unknown may have pressed), removes ONLY on successful release, release_all attempts all held items and retains failures. No Send/Sync promises for thread-bound devices.
