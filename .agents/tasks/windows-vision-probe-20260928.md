# 只读图像链路检查
只能用computer工具。禁止computer_step或任何输入；不能打开终端/浏览器/文件/源码。此次不是计算器验收。
1. computer_open时明确传max_width=960,max_height=540，然后computer_observe一次。
2. 若收到图片，直接看图，读出Computer Use Acceptance窗口中Trial编号和完整NONCE；描述图形的颜色及形状。答案只存在图片里。不能猜测、不能把黑色窗口当成显示器关闭。无法辨认则明确报告无法辨认，不再观察重试。
3. computer_close并结束。说明自己是否实际看到了图像；如果工具返回图片但你不能看懂，明确说明，不执行任何盲点操作。
