# 可选桌面反馈模块：已确认边界与验收契约

日期：2026-09-30。用户已确认产品职责；本文锁定首版边界与验收要求，不声称模块已实现或已真机验证。

## 1. 交付归属

| 内容 | 责任 |
|---|---|
| 移动/点击/拖拽/滚动/键盘与输入清理 | computer-use输入内核，必须提供 |
| AI操作标识、鼠标高亮/点击反馈、有效停止入口 | 本项目自带可选desktop-feedback模块，提供默认实现 |
| 颜色、文案、Logo、特殊动画 | 接入方可配置或替换默认展示实现 |

Runtime不依赖任何具体renderer；native-input不依赖反馈模块、UI框架、IPC、截图或模型。关闭/不加载模块不是降级输入模式，所有既有执行功能仍可用。

## 2. 首版优先级

P0：真实控制者/状态标识、可达且有效的停止入口、不开启时无UI副作用。
P1：轻量鼠标定位高亮和点击反馈，不默认改全局系统光标。
后置：蓝色光晕、Logo和特殊动画、对某产品完整视觉效果的复刻。

可选不等于丢给接入方自己实现：随项目提供默认组件与接线，应用只需选择启用/关闭或提供替代renderer。显式请求开启失败必须如实报告，不能悄悄隐藏错误、假称提示已显示。

## 3. 真实状态与执行位置

默认renderer运行在被控Host的交互桌面。Mac控制Windows时，标识/停止入口在Windows上；控制端可以另画连接状态，但不替代被控端反馈。

Runtime/Host是事实来源。UI区分：控制会话存在但等待Agent、观察截图中、实际动作执行中、暂停、停止/清理中、故障/状态未知、会话已关闭。不能把会话打开等同于持续注入，也不依据模型的自然语言“开始了/完成了”改变状态。

反馈事件仅含必要的session/控制代次、状态/序号、显示目标、位置/动作类别、清理结果，不含输入文本正文、凭据或截图。位置/动画可合并丢帧，权威状态通过最新snapshot重同步；慢renderer不得阻塞执行线程。

旧session的UI命令必须被拒绝，不能停止刚建立的新session。stop针对真实控制会话/代次，执行取消、清理和终止该控制权；不能只关窗口，也不能仅取消一次动作后继续接受旧session的新输入。新控制权如何再次授予需与Host既有会话/认证生命周期一致，不承诺永久屏蔽所有未来合法连接。

## 4. UI与平台安全

- 装饰区域不抢焦点、不拦截目标点击；停止控件有独立、明确、足够大的可交互区域。
- 鼠标穿透与截图排除是两项独立能力，不能用一项属性的成功代替另一项验证。
- 模型截图不应包含反馈层；必须由实际capture后端和平台配合验证。透明窗口不意味着自动排除。
- 不靠修改截图像素抹掉提示，不默认改用户全局光标；renderer本身不注入键鼠来“表现”反馈。
- Runtime/Host出错或断连时，区分已确认清理和清理失败/未知；不能先隐藏提示再给用户“已安全停止”的假保证。
- renderer崩溃不影响输入内核独立构建/运行。首版策略：未启用时零展示依赖；显式启用时启动/握手失败拒绝本次Host服务启动，运行中展示进程丢失、协议故障或心跳超时触发当前Host控制权终止及取消/清理，并明确诊断。不能静默继续或声称提示仍然可见；清理失败仍报失败/未知。
- 系统权限被拒绝或平台capture排除不支持时准确报能力/错误，不擅自改TCC、提权或全局系统设置。

## 5. 首版验收用例（均待实现/验证）

| ID | 情况 | 期望证据 |
|---|---|---|
| feedback-01 | 不加载/关闭 | 无UI子进程/窗口/新UI权限请求；核心原有动作与取消测试通过 |
| feedback-02 | 组件未安装但未启用 | 内核启动与动作正常，不因可选文件缺失失败 |
| feedback-03 | 显式启用但组件不可用 | 结构化诊断，不报“已显示” |
| feedback-04 | 远程Host | 用户可见标识在被控端实际桌面，Session0不是替代 |
| feedback-05 | 空闲持有控制 | 显示等待/已接管，不谎称正在点击 |
| feedback-06 | observe/step | 状态来自真实Host生命周期，并与action结果关联 |
| feedback-07 | 鼠标/点击反馈 | 位置对应目标显示器/最新geometry，不注入额外输入 |
| feedback-08 | 点击穿透 | 装饰覆盖下目标收到原始点击，反馈层不抢焦点 |
| feedback-09 | 停止可达 | 单独命中区域可点，不被整体穿透吞掉 |
| feedback-10 | 长拖拽中停止 | 正在执行动作被取消，自己持有的button释放，旧session不能继续输入 |
| feedback-11 | 长按/文本中停止 | 对应取消/清理，无多余残留输入；真实释放失败准确显示 |
| feedback-12 | 旧UI事件 | 老控制代次的stop被拒绝，新会话不被误停 |
| feedback-13 | 截图排除 | 同一时刻人可见、实际提供给模型的截图不含提示；与具体capture后端关联 |
| feedback-14 | 多屏 | 所控屏幕上的正确标识/位置，布局变化后不在错误区域显示 |
| feedback-15 | 断连/Host退出 | 区分关闭、清理中、失败/未知，无常驻错误蓝框或假安全报告 |
| feedback-16 | renderer异常/慢消费 | 执行线程不被卡住，展示丢失/重新同步有诊断 |
| feedback-17 | 样式替换 | 默认/自定义renderer共用相同状态及stop契约，不接管输入内核 |
| feedback-18 | 隐私与副作用 | 协议不发送文本正文/凭据/截图；不开启时无全局光标改变 |

Windows/macOS分别验证；纯状态/IPC测试不代替窗口焦点、点击穿透、截图排除的实机证据。蓝色光晕完成不是上述门禁完成的替代。
