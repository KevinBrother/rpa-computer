# Windows crossapp 01–06 — supervisor index, NOT an executable GUI authorization

Prepare only into a NEW absolute local private root. GUI remains blocked until
separately authorized and preflighted. Preparation/checking never launches,
activates, kills or configures an application, and never opens a listener.

## Publish only the selected generated agent task

The pack's `agent/` contains exactly six case-specific task.md files. Give the GUI
operator only the selected task in a source-free cwd. Do not publish supervisor
manifest/oracle, checker, implementation, local event logs or installation survey.
The application page/document is opened by the authorized supervisor, not through
an Agent file/shell/DOM tool. Only the eight computer MCP tools are permitted.

| Case | Visible identity / independent gate | Claim limit |
|---|---|---|
| 01 Notepad | Empty nonce-named asset document; supervisor confirms fresh owned HWND/PID/creation time/title, then operator saves a NEW result | Exact bytes/encoding check is artifact-only |
| 02 Calculator | No nonce UI exists; supervisor must identify the exact owned HWND and visible location immediately before trial | Three separate result screenshots/Observe IDs required |
| 03 Explorer | Owned nonce-bearing source/destination paths and 64 synthetic files; actual window identity preflight | 63+1 final hashes do not prove drag |
| 04 Offline browser | Visible case/trial/nonce; explicit owned browser HWND plus dedicated profile AND download confirmation | Export is untrusted application data |
| 05 Native drag | Original suite's independently generated inner case/trial/nonce | Same fixture, not a new external app |
| 06 Native focus | Original A/B/D scope and independently generated inner case/trial/nonce | Same process's windows are not multiple external apps |

**Installed apps/paths do not prove safe independent activation.** Never infer a
classic process from a System32 filename. If Store activation reuses protected
Notepad PID24332 or independent ownership is uncertain, mark needs_ownership and
STOP. A new tab in the protected process is not an exception. No launcher or
activation-switch exploration belongs to this pack.

For cases 05/06, supervisor must explicitly bind the OUTER pack run/case/nonce to
actual fixture run, PID/creation time/HWND and EACH inner case/trial/nonce. They
are not required or presumed equal. `reuse.binding_status` starts needs_preflight
and actual binding fields are null. Original task content stays intact; never
ask the Agent to open its source or widen its original suite's window scope.

Record first three frames, action-before/action-after/end frames, tool call IDs,
request IDs, based_on observation IDs, actual GLM label and first-vs-retry outcome.
Permission prompts, occlusion, unknown ownership, partial input or failed cleanup
mean STOP and computer_close, not prompt dismissal. No scope can be certified
from files, model self-report or generated manifests. `gui_verified` is always
false and the ten-first-valid-trials-per-action gate remains unmet.
